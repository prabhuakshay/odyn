## Directory Purposes

**src/odyn/:**
- Purpose: Main source code for the library
- Contains: Client, query builder, authentication, caching, exceptions
- Key files: `client.py` (1500+ lines), `cache.py`, `auth.py`, `exceptions.py`

**src/odyn/query/:**
- Purpose: OData query builder DSL
- Contains: Fluent builder pattern, field references, filter expressions
- Key files: `builder.py`, `fields.py`, `expressions.py`
- No dependencies outside query module except base types

**tests/:**
- Purpose: Pytest test suite with coverage tracking
- Contains: Unit and integration tests for all modules
- Key files: `test_client.py` (largest), `test_cache.py`, individual module tests
- Excludes: `tests/query/` contains dedicated query builder tests

**docs/:**
- Purpose: User documentation and guides
- Contains: Markdown files with setup, usage, API reference
- Not code; checked into git for distribution

**examples/:**
- Purpose: Runnable example scripts
- Contains: Real-world usage patterns
- Entry points for learning the library

**.planning/codebase/:**
- Purpose: GSD analysis output
- Contains: ARCHITECTURE.md, STRUCTURE.md, CONVENTIONS.md, TESTING.md, CONCERNS.md
- Generated by `/gsd:map-codebase` command

## Key File Locations

**Entry Points:**

- `src/odyn/__init__.py`: Public API exports (BCWebServiceClient, BasicAuth, APIKeyAuth, ParquetCache, ODataQuery, F, exceptions)
- `src/odyn/client.py`: BCWebServiceClient main class and helper protocols (ProgressCallback, RequestHook, ResponseHook)

**Configuration:**

- `pyproject.toml`: Dependencies (httpx, polars, aiolimiter), tool config (pytest, ruff, coverage)
- `.python-version`: Target Python version (3.13+)
- `CLAUDE.md`: Development commands and architecture overview

**Core Logic:**

- `src/odyn/client.py`: HTTP communication, pagination, retry, rate limiting, caching integration
- `src/odyn/query/builder.py`: OData query composition (select, filter, expand, order_by, top, skip, count)
- `src/odyn/query/fields.py`: F singleton and Field class for type-safe field references
- `src/odyn/query/expressions.py`: Filter expression classes and validation
- `src/odyn/auth.py`: BasicAuth and APIKeyAuth implementations
- `src/odyn/cache.py`: ParquetCache with TTL-based expiration
- `src/odyn/exceptions.py`: Exception hierarchy and error categorization
- `src/odyn/sync.py`: Synchronous wrapper for async client

**Testing:**

- `tests/test_client.py`: Comprehensive tests for client methods and resilience
- `tests/test_cache.py`: Cache functionality, TTL, expiration
- `tests/test_auth.py`: Authentication header generation
- `tests/test_exceptions.py`: Exception hierarchy and mapping
- `tests/test_resilience.py`: Retry, rate limit, timeout behavior
- `tests/query/test_builder.py`: ODataQuery fluent API
- `tests/query/test_fields.py`: F singleton and Field instances
- `tests/query/test_expressions.py`: Filter expression generation and composition
- `tests/query/test_types.py`: Type validation and value formatting

## Naming Conventions

**Files:**

- Python modules: `snake_case.py` (e.g., `cache.py`, `auth.py`)
- Test files: `test_*.py` (e.g., `test_client.py`, `test_auth.py`)
- Query submodule: `src/odyn/query/` contains builder, fields, expressions, types

**Directories:**

- Source: `src/odyn/` with nested `query/` submodule
- Tests: `tests/` with `query/` subpackage mirroring structure
- Utilities: `examples/`, `docs/` at root level

**Classes:**

- Client: `BCWebServiceClient`, `BCWebServiceClientSync`
- Query: `ODataQuery`, `Field`, `_FieldFactory`
- Auth: `BasicAuth`, `APIKeyAuth`
- Cache: `ParquetCache`, `CacheMetadata`
- Exceptions: `OdynError` base, specific subclasses (e.g., `ConnectionError`, `NotFoundError`)
- Expressions: `Comparison`, `InList`, `And`, `Or`, `Raw`

**Functions/Methods:**

- Public: `create()`, `get()`, `get_stream()`, `get_by_key()`, `count()`, etc.
- Private: `_request()`, `_handle_response()`, `_paginate()`, `_apply_rate_limit()` (leading underscore)
- Factory: `make_key()` static method in ParquetCache

**Constants:**

- Logger: `logger = logging.getLogger("odyn")`
- F singleton: `F: Final[_FieldFactory] = _FieldFactory()`
- Valid operators: `VALID_OPERATORS: Final[frozenset]`

## Where to Add New Code

**New Feature (e.g., new query method):**
- Primary code: `src/odyn/client.py` (add async method like `async def get_xyz()`)
- Tests: `tests/test_client.py` (add `TestBCWebServiceClientXyz` class with test methods)
- Query builder enhancement: `src/odyn/query/builder.py` (if ODataQuery needs new fluent method like `.xyz()`)

**New Filter Expression Type (e.g., substring search):**
- Implementation: `src/odyn/query/expressions.py` (create new class implementing FilterExpression protocol)
- Tests: `tests/query/test_expressions.py` (add test for new expression)
- Field integration: `src/odyn/query/fields.py` (if Field needs new method like `.contains()`)

**New Authentication Method:**
- Implementation: `src/odyn/auth.py` (create new frozen dataclass with `.apply()` method)
- Update: `src/odyn/auth.py` - `AuthStrategy` type alias to include new auth class
- Tests: `tests/test_auth.py` (add test class for new auth type)

**New Exception Type:**
- Implementation: `src/odyn/exceptions.py` (inherit from OdynError or WebServiceError)
- Export: `src/odyn/__init__.py` - add to `__all__`
- Usage: `src/odyn/client.py` - map HTTP errors to new exception type in `_handle_response()`

**Shared Utilities:**
- Helper functions: `src/odyn/` (create new module if needed, e.g., `utils.py`)
- Avoid: Don't duplicate validation logic; reuse `_validate_*()` functions from expressions.py

**Public API Changes:**
- Main exports: `src/odyn/__init__.py` - update `__all__` list
- Version: `src/odyn/__init__.py` - increment `__version__`

## Import Patterns

**Public API import:**
```python
from odyn import BCWebServiceClient, BasicAuth
from odyn.query import ODataQuery, F
```

**Internal imports within src/odyn:**
```python
from odyn.cache import ParquetCache
from odyn.exceptions import QueryValidationError, WebServiceError
from odyn.auth import AuthStrategy
from odyn.query import Field, ODataQuery
from odyn.query.expressions import FilterExpression
```

**TYPE_CHECKING block usage:**
- Used in all modules for forward references and type-only imports
- Example: `from odyn.auth import AuthStrategy` inside `if TYPE_CHECKING:` block
- Purpose: Avoid circular imports at runtime

**Relative imports:**
- Not used; all imports are absolute
- Simplifies refactoring and IDE navigation
